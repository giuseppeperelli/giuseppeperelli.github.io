##### Programma

- Introduzione ai sistemi per basi di dati: I sistemi per basi di dati; Funzionalit dei DBMS; Definizione della base di dati; Uso della base di dati; Controllo della base di dati; Distribuzione della base di dati.

- I modelli dei dati: Progettazione e modellazione; Considerazioni preliminari alla modellazione; Il modello entità-relazione; Il modello relazionale.

- La progettazione di basi di dati: Le metodologie di progettazione; L’analisi dei requisiti; La progettazione concettuale; Dipendenze funzionali; Chiusura di un insieme di dipendenze funzionali; Chiavi.

- Il modello relazionale: Il modello dei dati; I vincoli d’integrità; Progettazione logica relazionale; Algebra relazionale.

- Normalizzazione di schemi relazionali: Le anomalie; Decomposizione di schemi; Decomposizioni che preservano i dati; Decomposizioni che preservano le dipendenze; Forme normali; Accenni alla forma Normale di Boyce-Codd; Terza forma normale; Copertura di un insieme di dipendenze; Normalizzazione di schemi in 3NF.

- SQL per l’uso interattivo di basi di dati: Operatori per la ricerca di dati; Operatori per la modifica dei dati; Vincoli d’integrità; Procedure memorizzate; Trigger; Progettazione fisica; Definizione di indici; Schemi esterni.

- Accenni a SQL per programmare le applicazioni: Linguaggi che ospitano SQL; Connessione alla base di dati; Comandi SQL; I cursori; Transazioni; Gestione della concorrenza.

#### Modalità d'esame

La valutazione consiste nella stesura di un **progetto di gruppo** (*Max 3 studenti*) e una prova orale individuale.

Il progetto consiste nella formulazione di un modello dettagliato di base di dati, comprendente la sua strutturazione logica, la specifica dei vincoli di integrità e la sua normalizzazione. Inoltre è richiesta l'implementazione di query SQL sui dati progettati.

La prova orale consiste nella **discussione** (*individuale*) del progetto e un'**interrogazione** sui concetti, le definizioni, e i teoremi affrontati durante il corso.
